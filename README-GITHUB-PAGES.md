# Cleto & Botta — GitHub Pages

Pacote corrigido para o repositório `peltierextreme/cletoebotta-demonstracao`. Os caminhos dos recursos e links internos usam o prefixo `/cletoebotta-demonstracao/`, e há páginas index nas rotas internas.

## Como atualizar

1. Extraia o ZIP no computador.
2. No repositório GitHub, substitua os arquivos anteriores pelo conteúdo desta pasta. Envie também `.nojekyll`; se não aparecer no upload web, ative arquivos ocultos ou use GitHub Desktop.
3. Confirme em **Settings → Pages** que a publicação está definida para a branch `main`, pasta `/ (root)`.
4. Aguarde a publicação e acesse `https://peltierextreme.github.io/cletoebotta-demonstracao/`.

Este pacote está ajustado a esse nome de repositório. Se mudar o nome ou publicar sob outro caminho, os prefixos deverão ser ajustados. O mapa requer internet; o formulário abre o aplicativo de e-mail e não envia mensagens pelo site.
